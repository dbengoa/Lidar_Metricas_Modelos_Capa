# Descargar instalador

[⬇️ LiDAR forestal integrado 0.1.0 — ZIP para QGIS](https://github.com/dbengoa/Lidar_Metricas_Modelos_Capa/raw/refs/heads/main/descargas/lidar_forestal_integrado-0.1.0-experimental.zip)

Abra el archivo ZIP y pulse **Download raw** (flecha hacia abajo) si no se descarga
directamente. Instale sin descomprimir desde el administrador de complementos de
QGIS y reinicie QGIS. No use el ZIP de código fuente de todo el repositorio.
